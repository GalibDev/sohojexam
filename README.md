# SohojExam

SohojExam is a modern, mobile-first previous-question bank and smart exam preparation platform for engineering students in Bangladesh.

## Highlights

- Previous-question discovery by department, semester, subject, year, exam type, and college
- Repeated-question analysis and importance scoring
- Subject preparation progress and focused study plans
- Exam Mode and mock-test experience
- Interactive search and bookmarks
- Responsive desktop, tablet, and mobile web-app interface
- CSE question-bank experience, with more departments planned

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- vinext and Cloudflare Workers-compatible output

## Local development

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Product roadmap

The current release delivers the polished responsive front-end experience. Planned phases include authentication, database-backed questions, PDF upload and page mapping, PDF viewer, student dashboard, mock tests, study planner, contribution workflow, and admin management.
